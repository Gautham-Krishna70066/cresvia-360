# CRESVIA 360

The CRESVIA 360 website. A TanStack Start (React SSR) app built with Vite.

## Development

You need Node.js and npm.

```sh
npm install
npm run dev
```

The dev server runs on http://localhost:8080.

## Build

```sh
npm run build
npm run preview
```

Other scripts: `npm run lint`, `npm run format`, `npm test`.
